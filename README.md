# Rentify 🏠 - Real Estate Rental Platform

## 📝 Project Overview

Rentify is a comprehensive full-stack real estate rental platform designed to simplify the process of finding and managing rental properties. Built with cutting-edge technologies, Rentify provides an intuitive and efficient solution for both property seekers and landlords.

## 🌟 Key Features

- 🔍 Advanced Property Search
- 📋 Detailed Property Listings
- 👤 User Authentication & Profiles
- 📊 Dashboard for Property Management

## 🛠 Tech Stack

### Frontend

- Next.js 15
- React
- TypeScript
- Tailwind CSS

### Backend

- Spring Boot
- Java
- MySQL
- Spring Security

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- Java JDK (v17+)
- MySQL

### Installation

1. Clone the repository

```bash
git clone https://github.com/vuth9808/rentify-2
cd rentify-2
```

2. Setup Frontend

```bash
cd nextjs
npm install
npm run dev
```

3. Setup Backend

```bash
cd springboot
./mvnw spring-boot:run
```

4. Database Setup

- Import `Rentify.sql` in your MySQL database
